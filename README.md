# Moon System – Java OOP Project

A Java-based game project developed as part of FIT2099 Object-Oriented Design and Implementation at Monash University.

The project demonstrates object-oriented programming principles through the development of a turn-based game system with different actors, items, environments, and game mechanics.

## Features

- Object-oriented game architecture
- Multiple game actors and behaviours
- Items and inventory system
- Interactive game environments
- Custom ground and environmental mechanics
- Turn-based gameplay
- Extensible class structure

## Technologies

- Java
- Object-Oriented Programming (OOP)
- Git / GitHub
- IntelliJ IDEA

## OOP Concepts Applied

This project demonstrates:

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- SOLID design principles
- UML and software design

## Project Structure

`src/` – Java source code

`docs/` – UML diagrams and design documentation

object-oriented system, working with existing code, implementing new features,
using Git for version control, and documenting software design decisions.
